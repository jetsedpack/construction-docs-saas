# Совместная работа с диаграммами

- Основной источник схем — текстовые `.mmd` в `diagrams/`.
- Для обсуждения показывать схемы в Markdown через блок `mermaid`.
- Для свободного визуального рисования использовать `.drawio` и diagrams.net.
- Перед крупными изменениями создавать отдельную ветку и pull request.
- Не коммитить секреты, ключи, персональные данные и реальные закрытые строительные документы.
- В описании изменения указывать: что изменилось, почему, какие вопросы остались открыты.
- Codex может редактировать `.mmd` как код; после изменения проверять рендер и смысл связей.
