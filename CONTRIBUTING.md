# Как редактировать схемы совместно

- Визуальная схема — `diagrams/01-construction-data-flow.drawio`, редактировать в **diagrams.net**.
- Логические схемы Mermaid — файлы `.mmd`: редактировать в VS Code / Codex / ChatGPT текстовыми изменениями.
- `README.md` и `docs/architecture.md` показывают схемы Mermaid в интерфейсе GitHub без запуска графического редактора.
- Принятое изменение в одной нотации следует отражать в другой, если оно влияет на смысл.
- Для крупных изменений делать ветку и pull request; отдельные исправления могут идти прямыми коммитами при согласовании.
- Нельзя коммитить ключи, пароли, настоящие договоры, персональные данные и закрытые файлы объекта.
- При переписывании схем сохранять различие исходных утверждений, подтверждённых фактов и предложений ИИ.
- До просмотра реальных образцов не считать демонстрационные табличные сущности нормативно установленной системой.
