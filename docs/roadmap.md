# Дорожная карта — черновик

Этапы ниже — последовательность исследования и разработки, не обязательства по срокам.

1. **Discovery:** интервью с инженерами ПТО и подрядчиками; сбор обезличенных образцов; перечень типовых операций.
2. **MVP scope:** выбрать 1–2 документа и измеримый сценарий экономии времени; определить критерии качества.
3. **Прототип:** форма ввода, шаблонизатор, экспорт, ручная проверка; AI только там, где оправдан.
4. **Пилот:** испытание на реальных процессах с согласованным режимом доступа и обработки данных.
5. **Развитие:** расширение номенклатуры документов, интеграции, согласования, коммерческая модель.

## Метрики для пилота
- Время подготовки одного документа до/после.
- Доля документов, требующих исправлений.
- Число ручных переносов данных.
- Время согласования и число возвратов.
