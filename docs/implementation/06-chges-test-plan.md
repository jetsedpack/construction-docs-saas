# ЧГЭС: разбор источников и тестовый план

Источник: структура папки `05_Проекты_и_исследования / ИД_строительства — Discovery_2026-11 / ЧГЭС` в личном Google Drive владельца. В GitHub **нет копий закрытых документов и реальных персональных реквизитов**.

## Что подтверждено в кейсе
- Исходные: 13 вложенных шифров РД, 77 паспортов/сертификатов материалов, ССР Excel, договорно-распорядительные документы.
- Результаты: отдельные комплекты **электромонтажа** и **ПНР**.
- Электромонтаж: реестр ИД Excel; АОСР; исполнительные схемы; журналы входного контроля; акты технической готовности; ведомости изменений/недоделок; передача в ПНР; паспорта и документы качества.
- ПНР: реестр актов, 14 протоколов наладки, исполнительные схемы и 12 архивов конфигураций. Связь по позиционным обозначениям шкафов — потенциальный ключ графа.
- Три исследованных реестра (УА/УА1/УА2) — 42/28/39 записей соответственно, суммарно 109. Служебные графы «путь где лежит документ» и «дата направления на проверку» в этих строках пустые (возможно, хранились в другом месте).
- В одном реестре неоднозначность количества листов / диапазона: позиция 5 — 3 листа vs диапазон 4–7 (4 страницы) и потенциальное пересечение. **Признак на проверку, не доказанный дефект готового комплекта**.
- Ведомость изменений содержит 11 отличий длин кабельных линий; графа согласований прочерки. Не утверждать, что согласований не было без смежных документов.
- В некоторых названиях и реестрах различаются похожие обозначения шкафов; проверить оригиналы, прежде чем классифицировать как ошибку.

## Тестовые сценарии
| ID | Given | When | Then |
| --- | --- | --- | --- |
| CHG-001 | Реестр с листами=3, pages=4–7 | Локальная проверка | `page_count_mismatch`, evidence=строка |
| CHG-002 | Запись содержит диапазон, пересекающий предыдущий | Локальная проверка | `page_overlap`, severity=review |
| CHG-003 | В реестре нет пути к документу | Локальная проверка | `missing_link`, но не автоматически «нарушение» |
| CHG-004 | РД с revision=2, акт с revision=1 | Нормализация идентификаторов | Предложение проверить применимость редакции |
| CHG-005 | Изменена длина кабеля, approval_evidence пуст | Проверка связей | `approval_missing` на ручную верификацию |
| CHG-006 | Название серт. совпадает, номер отличается | Материал и evidence | Найти конфликт, не дедуплицировать по имени |
| CHG-007 | Один шкаф в акте, протоколе, config archive | Граф связей | Единая Equipment entity и несколько DocumentLinks |
| CHG-008 | Срок действия сертификата в имени, реестр содержит дату как выдачу | Date-semantic check | Flag `date_semantics_uncertain` |
| CHG-009 | Сканы PDF без текстового слоя | Импорт | Статус `requires_ocr`; не придумывать текст |
| CHG-010 | Реальные конфигурации РЗА | Secure transport | Не отправлять на GPUGO — payload только код finding |

## Форма эталонной разметки для эксперта
`source_id, row/page, entity_type, field, expected_rule, true_issue, severity, rationale, source_evidence, accepted_remediation, reviewer`. Для тестов — синтетические данные, оригиналы остаются в Drive.

## Критерии PoC
- 100% PoC исходных файлов остаётся локально; capture сетевого исходящего трафика не содержит имён/номеров/текста.
- Локальные правила детерминированны и воспроизводимы.
- У каждой находки id категории, краткое описание и номер исходной строки.
- Передаваемые AI поля совпадают со схемой allowlist; попытки добавить `raw_text`, `filename`, `organization` отклоняются тестами.
- Ошибка / таймаут AI не блокирует доступ к локальным файлам и не меняет ни одной подтверждённой записи.
- MVP не обещает 100%-ную юридическую полноту комплекта.
