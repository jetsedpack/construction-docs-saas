# Acceptance gates / определение готовности

## До показа демо
- [ ] Приложение запускается на чистой Windows 11 x64.
- [ ] Открывает тестовый XLSX с несколькими листами и локально показывает ошибки нумерации.
- [ ] Тестовый PDF/DOCX распознаётся локально (без OCR).
- [ ] Исходные байты не оказываются в виде plaintext в рабочих каталогах и исходящем HTTP.
- [ ] Вход в GPUGO отключён, если пользователь не указал endpoint+token и не подтвердил конкретный запрос.
- [ ] Ошибка/таймаут модели оставляют реестр без изменений.
- [ ] No prompt / response log на клиенте и worker.
- [ ] pytest проходит на Windows runner.
- [ ] В интерфейсе однозначно обозначены **предложения ИИ**, а не юридически утверждённые факты.

## До доступа реальных пользователей
- [ ] Требования ПТО утверждены, есть эталонная разметка 30+ документов.
- [ ] Security review / DPA / классификация данных и модель угроз.
- [ ] Ключи доступа не в .env/исходниках, выданы по tenant и ограниченному сроку жизни.
- [ ] Проверен бэкап+восстановление DPAPI-ключей и документов.
- [ ] Подписанный Windows installer и механизм безопасных обновлений.
- [ ] OCR/DWG/DOC/XLS/RAR — либо поддержка с изоляцией парсеров, либо явная блокировка.
- [ ] Неизменяемый реестр событий, роли, возможность отзыва полномочий.
- [ ] Отдельная процедура юридической приёмки и ЭП.
- [ ] Нормативы: версии, обязательность, даты действия, источник, проверка экспертом.
- [ ] Логирование/буферизация GPUGO не содержат содержимого исходных документов.
- [ ] Нагрузочные тесты на подтверждённых RTX PRO 6000D, benchmark качества модели.

## Неочевидные негативные сценарии
- Акт не совпадает с РД: невозможно доказать, где источник истины → показать конфликт, не менять акт.
- Текущая редакция нормы не действовала на дату выполнения → выбрать правильную редакцию.
- Заводской паспорт в двух комплектах → не создавать два разных оборудования по имени файла.
- Файл PDF содержит скан, извлечение пусто → явный статус «нужен OCR».
- Правило совпадает по маркировке, но другой шкаф/секция → запросить подтверждение.
- Шифр РД отличается одним символом → ошибку маркировки не признавать доказанным нарушением без проверки.
- Папка с RAR конфигурациями РЗА → не распаковывать и не загружать в inference автоматически.
