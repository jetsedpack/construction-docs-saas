# Windows UX, инсталляция и эксплуатация

**Платформа:** Windows 10/11 x64; пилот тестировать на Windows 11. Python 3.11–3.13 + PySide6. macOS/Linux не целевые; Android/iOS/iPad не планируются.

## Экраны
1. **Проекты** — объект, этапы, шифры РД, проверенные редакции, текущая комплектность.
2. **Загрузка** — drag&drop или FileDialog; форматы PDF (текстовый слой), DOCX, XLSX, CSV. Сразу отметить «не поддержано», если скан без текстового слоя, старый DOC/XLS, DWG или RAR.
3. **Источники** — документ и локальная ссылка на фрагменты; исходный файл неизменяем.
4. **Реестр ИД** — фильтры по разделу и виду, статус проверки, документ, страницы, дата, ответственный, комплект.
5. **Замечания** — слева список, справа две версии данных/основания/последствия; кнопки «Проверить», «Отклонить», «Запросить данные».
6. **Связи** — работа → РД → оборудование → сертификат → акт → исполнительная схема → ПНР.
7. **AI запрос** — перед отправкой **показывать конкретный обезличенный payload** и домен шлюза; явное подтверждение, отзыв.
8. **История** — автор, дата, исходные версии, решение, журнал; локально в PoC.
9. **Экспорт** — только после human approval; проверка формата и юридической формы — отдельный этап.

## PoC интерфейс в текущем коде
Минимальный экран PySide6: список документов; импорт; проверка Excel реестра; журнал находок; отдельная кнопка AI-подсказки при настроенном URL. Не путать с полной экранной спецификацией выше.

## Установка разработчика на Windows
```powershell
git clone https://github.com/jetsedpack/construction-docs-saas.git
cd construction-docs-saas
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[desktop,dev]"
python -m construction_docs.desktop
```
Запуск без GPUGO токена поддерживает импорт и локальные правила, AI недоступен.

## Сборка
`pyside6-deploy run_windows.py --mode onefile` — направление для эксперимента, **не проверенная сборка**. Готовый скрипт: [packaging/build_windows.ps1](../../packaging/build_windows.ps1); entrypoint — [run_windows.py](../../run_windows.py). Для выпуска: зафиксировать Python и PySide6, отдельный windows runner CI, подписать exe, AV-скан, installer + app update, SBOM и проверка зависимостей, тест инсталляции на чистой VM. Официальные инструкции: https://doc.qt.io/qtforpython-6/deployment/deployment-pyside6-deploy.html

## Локальные данные
`%LOCALAPPDATA%\ConstructionDocsPoC\`: `vault.sqlite3` — только ciphertext чувствительных полей, `blobs/<uuid>.enc` — шифрованные файлы, `master.dpapi` — Fernet key, защищённый текущим Windows-пользователем через DPAPI. **Внимание:** это не полноценное шифрование всей БД SQLCipher; индексы и служебные времена открыты. Нужны NTFS ACL, BitLocker, политики резервного копирования, восстановление ключей и контроль привилегированного доступа.

## Отказоустойчивость
- GPUGO недоступен: локальные проверки продолжают работать.
- Сеть обрывается: никакие правки в реестре не применяются.
- Файл не распознан: оставлять оригинал с статусом «нужна ручная разметка», не фантазировать содержание.
- Ключ DPAPI утрачен или изменён Windows-профиль: возможна потеря доступа; продумать безопасный экспорт backup-ключей до пилота с реальными данными.
