# Помощник ПТО — браузерное демо

Откройте `index.html` в браузере. Для стабильного сохранения состояния между перезапусками удобно запустить локальный сервер из папки `demo`:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8000`. Сборка и сторонние зависимости не требуются.

## Сценарий ПТО

1. На обзоре откройте замечание о паспорте качества и добавьте синтетический паспорт К-214.
2. Запустите проверку, откройте замечание о редакции РД и подтвердите редакцию 03. Она попадёт в черновик, исходные реквизиты акта сохранятся.
3. Повторите проверку и откройте комплект. Просмотрите черновик АОСР, подтвердите просмотр и скачайте реестр CSV.
4. В разделе «Исходные файлы» можно открыть источник, отфильтровать реестр, назначить тип документа или импортировать JSON. Кнопка «Скачать пример» выгружает исходный синтетический комплект в поддерживаемом формате.

## Границы демо

Сценарий охватывает один участок с одним чертежом и одним АОСР. Проверка комплектности работает по демонстрационному чек-листу. Импорт обрабатывает структурированные реквизиты JSON. Документы представлены синтетическими записями. Состояние хранится в браузере, выпуск ограничен CSV и просмотром черновика. Для работы с реальными материалами предусмотрен Windows-контур проекта. Веб-демо не подключено к его хранилищу, парсерам и GPUGO Edge.
