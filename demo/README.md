# Помощник ПТО

## Открыть демо

[Откройте демо](https://construction-docs-demo.vkaravaev.chatgpt.site/) и войдите через ChatGPT.

Для локального запуска выполните команды:

```sh
git clone --branch codex/clickable-id-mvp https://github.com/jetsedpack/construction-docs-saas.git
cd construction-docs-saas
python -m http.server 8000 --bind 127.0.0.1 --directory demo
```

Откройте [localhost:8000](http://localhost:8000).

## Собрать комплект ИД

1. На экране «Обзор» откройте замечание «Не хватает паспорта качества» и нажмите «Добавить паспорт К-214».
2. Нажмите «Запустить проверку». Откройте замечание по редакции РД и нажмите «Подтвердить редакцию РД 03».
3. Снова запустите проверку. Когда замечаний не останется, нажмите «Открыть комплект».
4. Просмотрите черновик АОСР, нажмите «Подтвердить просмотр» и скачайте реестр CSV.

## Открыть свой комплект

В разделе «Исходные файлы» нажмите «Скачать пример». Заполните JSON по примеру и загрузите его через «Импорт JSON». Проверьте типы документов в реестре и запустите проверку.

Чтобы вернуться к стартовому комплекту, нажмите «Сбросить демо».
